# Calculadora de Nota Promedio

Aplicación desarrollada en **Java** con **Spring** y gestionada mediante **Maven**. Permite introducir varias notas y calcular automáticamente la nota media.

## Tecnologías utilizadas

- Java
- Spring
- Maven
- Interfaz gráfica de usuario
- Git / GitHub

## Uso

1. Introducir la nota que se quiere evaluar.
2. Ejecutar el cálculo.
3. El programa arroja el promedio de notas.
4. Introducir la siguiente nota

## Objetivo

El proyecto sirve como práctica de desarrollo de aplicaciones Java utilizando **Spring y Maven**, así como de gestión de entradas de usuario, cálculo de datos y organización de un proyecto mediante una estructura estándar.
